# Resource Paper Release — 2026

This directory contains the frozen artifacts for the resource paper release
(v2.0) of the Japanese Given Names dataset.

## Contents

```
releases/resource-paper-2026/
  README.md          — this file
  checksums.txt      — SHA-256 checksums of all frozen files (generated last)
  outputs/
    figures/         — paper figures (copied from scripts/output/ at freeze time)
    tables/          — paper tables (JSON/TSV, generated by pub-tables.py)
```

## How to rebuild

```bash
make paper-release
# or:
bash releases/resource-paper-2026/build.sh
```

This regenerates cleaned data exports, validation report, paper tables and
figures, and checksums. Requires the database to already be built
(`bash makedb.sh db`).
